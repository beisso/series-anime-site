# Series & Anime — página pública

Página estática de apresentação do **Series & Anime**, um aplicativo para descobrir, organizar e acompanhar séries e animes.

- **Status:** em desenvolvimento.
- **Plataforma inicial:** Android.
- **Download:** ainda não disponível.

A página usa somente HTML e CSS estáticos, publicados pelo GitHub Pages. Não usa APIs, banco de dados, rastreamento ou serviços externos. Este repositório **não contém o código do aplicativo**.

## Arquivos

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Página em português |
| `styles.css` | Estilos (temas claro e escuro) |
| `assets/favicon.svg` | Ícone da página |
| `assets/tmdb-logo.svg` | Logotipo oficial do TMDB ("Primary short (blue)"), arquivo original sem modificação, obtido em https://www.themoviedb.org/about/logos-attribution |
| `.nojekyll` | Publica os arquivos sem processamento do Jekyll |

## Créditos

Os dados e as imagens de séries e animes do aplicativo serão fornecidos pelo [TMDB](https://www.themoviedb.org).

This product uses the TMDB API but is not endorsed or certified by TMDB.
